# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue in Motus, please report it responsibly.

**Please do NOT open a public GitHub issue for security concerns.**

Instead, email **security@openmotus.org** with:

- A description of the issue
- Steps to reproduce
- Potential impact

We will acknowledge receipt within 48 hours and aim to provide a fix or mitigation within 7 days for critical issues.

## Scope

This policy applies to the Motus framework codebase at [github.com/openmotus/motus](https://github.com/openmotus/motus).

## Disclosure Policy

We follow coordinated disclosure. We ask that you:

1. Allow us reasonable time to address the issue before public disclosure
2. Make a good faith effort to avoid privacy violations, data destruction, and service disruption
3. Only interact with accounts you own or with explicit permission

## Recognition

We appreciate the security research community and will acknowledge contributors who report valid issues (with your permission) in our release notes.
